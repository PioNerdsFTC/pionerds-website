# Pionerds Website

A typical Sveltekit App. We've added MDsveX for markdown powered blog posts - if we ever get around to it. 

## Development

This project relies on bun, make sure you have that preinstalled.
To run the project, use ```bun dev```

## Style

The style-guide resides at ```/style-guide```. It isn't a very strict document, it just outlines some components and how they work.
